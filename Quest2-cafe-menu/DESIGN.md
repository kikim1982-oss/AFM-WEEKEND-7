# StarPresso 프로젝트 – 스타벅스 리서치

> 컨셉: **스타벅스 디자인 골격 + 바나프레소 컬러 액센트 = StarPresso**
>
> 조사 출처: starbucks.co.kr (실제 CSS·DOM 분석) / 2026-05-14

## 2. 컬러 시스템 (실제 CSS 추출)

### 메인 컬러
| 역할 | HEX | RGB | 사용처 |
|---|---|---|---|
| **Starbucks Green** | `#006633` | rgb(0, 102, 51) | 로고, CTA, 강조 텍스트 |
| **Espresso Black** | `#2C2A29` | rgb(44, 42, 41) | 헤더, 푸터 배경 |
| **Warm Brown** | `#76685E` | rgb(118, 104, 94) | 서브 배경, 카드 |
| **Sand Beige** | `#8C8279` | rgb(140, 130, 121) | 액센트, 보더 |
| **Cream Paper** | `#F4F4F2` | rgb(244, 244, 242) | 본문 배경 |
| **Pure White** | `#FFFFFF` | rgb(255, 255, 255) | 카드 배경 |

> 참고: 글로벌 스타벅스 공식 그린은 `#00704A`(House Green). 한국 사이트는 `#006633` 변형 사용.

### 텍스트 계조
```
#000000 (본문)  →  #222222  →  #444444  →  #666666  →  #999999
```

### 🎨 StarPresso 제안 팔레트 (핑크 메인 + 오렌지 포인트 + 에스프레소 블랙)
| 역할 | HEX | 비중 | 비고 |
|---|---|---|---|
| **Primary (브랜드)** | `#F1658A` | **70%** | **바나프레소 시그니처 핑크** — 헤더·메인 CTA·로고·브랜드 전반의 기조색 |
| **Point (포인트)** | `#FF8A4C` | **15%** | **비비드 오렌지** — NEW 배지·하이라이트·특가/이벤트 강조. 핑크와 같은 따뜻한 계열로 충돌 없이 시너지 |
| **Espresso Black** | `#2C2A29` | **15%** | 스타벅스 에스프레소 블랙 — 본문 텍스트·헤더 다크 모드·푸터 배경. 핑크의 발랄함을 무겁게 잡아줌 |
| Surface | `#FFFFFF` / `#FFF5F7` | – | 본문 배경(화이트) + 미세한 핑크 틴트 서브 배경 |
| Text Sub | `#76685E` | – | 보조 텍스트 (설명·캡션) |
| Text Primary | `#1A1A1A` | – | 본문 텍스트 |

→ **핑크 70% + 오렌지 15% + 에스프레소 블랙 15%** 비율을 권장. 핑크가 메인 베이스를 점령하고, 오렌지는 "지금 봐!" 신호용 포인트(NEW·세일·이벤트)로만 한정 사용, 블랙은 텍스트·푸터 무게중심으로만 사용해 발랄함과 안정감의 균형을 유지.

> 💡 **사용 룰**: 한 화면에 오렌지는 1-2개 요소까지만. 오렌지가 많아지면 핑크 브랜드 인지가 흐려짐. 그린(#006633)은 **더 이상 사용하지 않음** — 핑크 기조로 완전 전환.

## 3. 폰트 시스템 (실제 사용 비율)

| 우선순위 | 폰트 | 카운트 | 역할 |
|---|---|---|---|
| 1 | `nbg` (Naver Brand Gothic) | 1,515 | 본문 90% – 한글 메인 |
| 2 | `Avenir` | 14 | 영문 헤드라인 / 로고 옆 카피 |
| 3 | `Noto Sans KR` | 38 | NBG 폴백 |
| 4 | `NanumBarunGothic` | 4 | 일부 본문 |
| 5 | `맑은 고딕` / `Arial` | – | 시스템 폴백 |

### 글로벌 브랜드 폰트 (참고)
- 스타벅스 본사는 **SoDo Sans**(헤드라인) + **Lander Grande**(본문)을 사용. 라이선스 문제로 한국 웹에선 사용 안 함.
- 따라서 한국 디지털 환경에선 **Avenir + NBG** 조합이 사실상 표준.

### 🔤 StarPresso 폰트 제안
| 용도 | 폰트 | 굵기 |
|---|---|---|
| **Display / 영문 로고** | Avenir Next (or Montserrat 대체) | 700 |
| **헤딩 한글** | Pretendard Bold | 700 |
| **본문 한글** | Pretendard | 400/500 |
| **숫자·가격** | Avenir Next | 600 |

> Pretendard = NBG의 모던 오픈소스 대체재. 무료 + 한·영·숫자 통일성 최고.

## 4. 사진 스타일 가이드

### 음료 (menu/*)
- **포맷**: 300×313 정사각형에 가까운 비율
- **배경**: 순수 화이트 (`#FFFFFF`) — 누끼컷 100%
- **앵글**: 컵 정면, 살짝 위에서 비스듬히
- **그림자**: 거의 없음 (제품 자체 명도 대비로 분리)
- **컵 디자인**: 흰 컵 + 사이렌 로고 + 녹색 빨대. 통일성으로 브랜드 인지.

### 매장 (stores/*)
- **포맷**: 가로형 또는 세로형 (다양)
- **분위기**: 자연광 + 우드톤 인테리어 + 사이렌 로고가 보이는 외관 컷
- **샷 종류**:
  - DT(드라이브스루) 외관 — `01_anyang-hogye-DT.jpg`
  - 호수/뷰 매장 외관 — `02_cheonan-dankook-lake.jpg`
  - 백화점 입점 매장 인테리어 — `03_shinsegae-southcity-9F.jpg`, `04_newcore-gangnam.jpg`
  - 도심 거리형 매장 — `05_sunhwadong-police-front.jpg`

## 6. StarPresso 구현 가이드 (Quest2 적용)

### UI 컴포넌트별 가이드
| 컴포넌트 | 메인 (핑크 70%) | 포인트 (오렌지 15%) | 뉴트럴 (블랙 15%) |
|---|---|---|---|
| **헤더** | 핑크 `#F1658A` 바, 흰 로고/텍스트 | – | – |
| **메인 CTA (주문하기)** | 핑크 솔리드 버튼 (기본) | – | 호버 시 블랙 보더로 강조 |
| **신메뉴·이벤트 배지** | – | **오렌지 `#FF8A4C` 배경**, "NEW" / "HOT" / "이벤트" | – |
| **카드** | 흰 배경, 핑크 가격 텍스트 | NEW/한정 배지에만 오렌지 | 블랙 본문 텍스트 |
| **메뉴 그리드** | 정사각 누끼컷, 가격은 핑크 강조 | 오렌지 배지로 추천/할인 표시 | – |
| **메뉴 카테고리 탭** | active 탭 핑크 텍스트 + 핑크 언더라인 | – | inactive는 회색/블랙 |
| **푸터** | – | – | `#2C2A29` 다크 배경 + 화이트 텍스트 |
| **링크/강조 텍스트** | 핑크 | – | 블랙 본문 |

### 톤 & 매너 비교
| 항목 | 스타벅스 | 바나프레소 | StarPresso (믹스) |
|---|---|---|---|
| 무드 | 정제·고급·차분 | 발랄·빠름·가성비 | **발랄하면서 모던** |
| 컬러 비중 | 그린+브라운 95% | 핑크+화이트 90% | **핑크 70 + 오렌지 15 + 블랙 15** |
| 카피 톤 | "오늘의 한 잔" 같은 잔잔함 | "PINK ME UP!" 같은 임팩트 | 짧고 친근하면서 임팩트 있게 |
| 사진 | 자연광·인테리어 강조 | 누끼·제품 강조 | 둘 다 사용, 그리드는 누끼 |
| 폰트 | NBG·Avenir | Pretendard·GmarketSans | **Pretendard + Avenir** |

### 한 줄 컨셉
> **"핑크가 무대를 점령하고, 오렌지가 손을 들고, 블랙이 마이크를 잡는다."**
> – 따뜻한 핑크 베이스 위에 오렌지 포인트로 활력을, 블랙 텍스트로 무게감을 더한 발랄-모던 카페 UI.
