## 1. 컬러 팔레트 (3가지 핵심 컬러)

바나프레소의 색은 "커피의 진중함"과 "핑크의 발랄함"을 충돌시킨 구조다. 베이지·우드톤 일색인 일반 카페 시장에서 의도적으로 튀는 포지셔닝.

### 1️⃣ Signature Pink — `#F1658A` (rgb(241, 101, 138))
- 슬로건 "PINK ME UP"의 주인공. 로고, CTA 버튼, 액센트 배경, 시즌 배너에 사용.
- 채도가 높지만 형광 핑크보다 한 단계 다운된 **로즈핑크**라 음식 사진과 충돌하지 않음.
- 브랜드 인지도의 90%를 이 한 색이 책임짐.

### 2️⃣ Espresso Brown — `#292022` (rgb(41, 32, 34))
- 메인 텍스트 / 풋터 / 헤더에 사용되는 거의 검정에 가까운 **딥 다크 브라운**.
- 순수 검정(`#000`)이 아닌 약간의 적갈색 톤 → "갓 내린 에스프레소" 컬러.
- 핑크의 화려함을 무게감으로 잡아주는 역할.

### 3️⃣ Pure White — `#FFFFFF`
- 전체 배경의 95%를 차지하는 **클린 화이트**. 베이지/크림이 아닌 순백.
- 메뉴 사진을 누끼컷 + 화이트 배경으로 통일시켜 "정직하고 깔끔한 가성비" 인상을 줌.
- 흰 배경 위 핑크 액센트 = 가시성 극대화 (앱·키오스크 환경에 최적화된 선택).

### 보조 컬러
| 색 | HEX | 용도 |
|---|---|---|
| Muted Wine | `#574045` | 서브 텍스트, 카테고리 라벨 |
| Gray 70 | `#333333` | 본문 텍스트 |
| Gray 50 | `#666666` | 캡션, 가격 표기 |

```
■ #F1658A  Signature Pink   (브랜드 / CTA)
■ #292022  Espresso Brown   (텍스트 / 헤더)
□ #FFFFFF  Pure White       (배경)
```

## 2. 대표 폰트 (2가지)

실제 `font-family` CSS 사용 비율 (231 / 58 / 18 …) 기준 상위 2종.

### 1️⃣ Pretendard — 본문·UI 전반
- 한·영·숫자 통일감이 가장 좋은 **모던 한글 산세리프**.
- 주문 화면, 메뉴 설명, 가격, 가맹 안내 등 사이트 컨텐츠 **본문 90%** 차지.
- 400(Regular) / 500(Medium) / 700(Bold) 가중치로 위계 구성.
- 선택 이유 추정: 토스·당근 등 한국 IT 서비스에서 사실상 표준 → "친숙한 디지털 가독성" 확보.

### 2️⃣ GmarketSans — 디스플레이·헤드라인
- G마켓이 무료 배포한 **두꺼운 디스플레이체**. 라운드한 인상에 무게감이 있어 광고 배너·슬로건에 사용.
- "PINK ME UP", "빙수의 정석", "과채의 세계" 같은 캠페인 카피의 큰 글자에 등장.
- Bold/Heavy 가중치 위주 사용 → 직관적이고 큼지막한 인상.

### 보조 폰트
- `Noto Sans KR` — Pretendard 미지원 환경의 폴백.
- `Arial` — 영문 시스템 폴백.

```
폰트 위계
  Display / Hero   →  GmarketSans Bold/Heavy
  Heading / Title  →  Pretendard 700
  Body / Caption   →  Pretendard 400-500
```

## 3. 카페 분위기 (Brand Mood)

바나프레소는 분위기로 머무는 카페가 아니라 **사고 나가는 카페**다. 인테리어보다 가격표와 사이즈가 먼저 보이는 브랜드.

### 키워드 5개
1. **빠른 (Quick)** — 슬로건의 "빠른 행복". 키오스크·앱 선주문 최적화.
2. **큰 (Big-size)** — 메가커피·컴포즈와 함께 빅사이즈 저가커피 3대장. 모든 음료 잔이 크다.
3. **가성비 (Value)** — 합리적 가격을 메인 카피에 노출. 아메리카노 1,500원대 포지셔닝.
4. **발랄한 (Playful)** — 핑크 메인 컬러, 캐릭터 "에티(Eti)" 굿즈, 뽀로로 콜라보 키즈 음료.
5. **모던 (Modern)** — 우드·앤틱 카페의 반대편. 화이트+핑크+다크브라운의 도시적 카페.

### 공간 톤
- 매장 인테리어: 흰 벽 + 핑크 사인 + 우드 데스크 → 미니멀한 테이크아웃 부스.
- 좌석: 많지 않음. 머무는 공간보다 픽업 동선 중심.
- 사진/광고: 누끼컷 위주, 흰 배경에 음료를 정면 배치 → 메뉴판/앱 친화적.

### 톤 & 매너
- 친근하지만 가볍지 않음. 핑크로 친밀감을 주고 다크브라운으로 신뢰를 받친다.
- 카피 어투: "PINK ME UP!", "더 크게 더 맛있게" 처럼 **명령형·감탄형** 짧은 구호.
- 이모티콘·과한 꾸밈 없음. 깔끔한 산세리프 + 큰 사진.

## 4. 타겟 손님 (Target Audience)

### 🎯 1차 타겟 — 20대 후반 ~ 30대 직장인 (테이크아웃족)
- 매일 1잔, 가성비가 최우선. "스벅 가격의 1/3로 점심 후 커피".
- 사무실 근처 매장에서 앱 미리주문 → 픽업.
- 라떼·아메리카노 빅사이즈 선호.

### 🎯 2차 타겟 — 대학생 / 20대 초반
- 시험기간·과제용 학습 카페로 가기엔 좌석이 부족, 대신 **친구와 산책하며 마시는 컵** 포지션.
- 시즌 메뉴(핑크 아메리카노, 두바이 초코라떼, 라임민트 스파클러)를 SNS에 인증.
- 마카롱·붕어빵 등 디저트를 함께 픽업.

### 🎯 3차 타겟 — 키즈 동반 가족 / 알뜰 주부
- 뽀로로 콜라보 음료(뽀로로딸기·뽀로로보리차) 라인업으로 어린이 음료 흡수.
- 베이커리 박스, 컵빙수 같은 가족용 메뉴.
- 합리적 가격으로 매일 부담 없이 사용.

### ❌ 비타겟
- 스페셜티 원두 애호가 (단일 산지 강조 없음).
- 카페에서 오래 머무르고 싶은 작업/스터디족 (좌석 회전 중심).
- 인테리어·분위기 자체를 소비하려는 감성 카페 고객 (블루보틀·앤트러사이트 류).
