# Design] 카페 메뉴판 만들기

<aside>
🎯

내가 카페 사장이라고 상상해보세요. 손님이 처음 봤을 때 **"여기 들어가고 싶다"** 싶은 **카페 메뉴판 한 장**을 디자인하세요.

</aside>

---

## 미션

### Part 1: 카페 컨셉 잡기

- 카페 이름, 분위기(예: 미니멀 / 빈티지 / 코지), 타겟 손님을 한 줄씩 정리
- 컨셉에 맞는 **컬러 팔레트(3색 이내)**와 **폰트(2개 이내)** 선정

### Part 2: 메뉴 구성

- 카테고리 **3개 이상** (커피 / 논커피 / 디저트 등)
- 메뉴 **8개 이상**, 가격 포함
- 시그니처 메뉴 **1개 선정**

### Part 3: 메뉴판 디자인

- 사이즈: A4 세로 또는 1080×1350
- 시그니처 메뉴는 **사진·일러스트 + 강조색**으로 시선을 잡기
- 카테고리 위계가 한눈에 보이도록 정렬

### Part 4: 공유

- 단톡방 또는 인스타 스토리에 메뉴판 공유

---

## 제출물

- GitHub 저장소 링크 (코드/리소스 포함)
- 메뉴판 이미지 (PNG 또는 PDF)
- 카페 컨셉 한 단락 설명
- 에이전트와의 대화 스크린샷 (최소 1장)

---

## 포인트 획득 기준

| **항목** | **포인트** | **기준** |
| --- | --- | --- |
| 기본 완료 | 10pt | 메뉴판 이미지 + 컨셉 설명 제출 |
| 에이전트 활용 | 5pt | 에이전트와 2회 이상 대화하며 결과물을 개선한 흔적 |
| 창의성 | 5pt | 컨셉이 살아있는 톤앤매너 + 시그니처 메뉴 강조 |
| 공유 보너스 | 5pt | 단톡방·인스타에 공유하고 다른 수강생에 리액션 |

| **달성 수준** | **획득 포인트** |
| --- | --- |
| 기본 제출 | 10pt |
| 기본 + 활용/창의성 | 15~20pt |
| 올클리어 (전항목 달성) | **25pt** |
