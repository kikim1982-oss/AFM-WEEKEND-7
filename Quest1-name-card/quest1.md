# Design] 내 명함 만들기

<aside>
🎯

처음 만난 사람이 5초 만에 **"이 사람 뭐 하는 사람이지?"**를 알 수 있는 **내 명함**을 디자인하세요.

</aside>

---

## 미션

### Part 1: 나를 한 단어로 정의

- 직함 또는 태그라인 **한 줄** ("프론트엔드 개발자" / "노코드로 앱 만드는 디자이너" 등)
- 내가 가장 보여주고 싶은 **포인트 1개** 선정

### Part 2: 핵심 정보 정리

- 이름, 직함, 연락처(이메일·전화·링크 1~2개)
- 정보는 **5가지 이내**로 압축

### Part 3: 명함 디자인

- 사이즈: **90×54mm** (표준 명함)
- 앞면 + 뒷면 (뒷면은 QR / 슬로건 / 포트폴리오 링크 등)
- 핵심 포인트 1개에만 **강조 스타일** (크기·색)

### Part 4: 출력/공유

- PDF로 출력하거나 단톡방에 이미지 공유

---

## 제출물

- GitHub 저장소 링크
- 명함 이미지 (앞/뒤)
- 한 줄 컨셉 설명 ("나를 한 단어로 정의하면 ___")
- 에이전트와의 대화 스크린샷 (최소 1장)

---

## 포인트 획득 기준

| **항목** | **포인트** | **기준** |
| --- | --- | --- |
| 기본 완료 | 10pt | 앞/뒤 명함 이미지 + 컨셉 한 줄 제출 |
| 에이전트 활용 | 5pt | 에이전트와 2회 이상 대화하며 결과물을 개선한 흔적 |
| 창의성 | 5pt | 나만의 톤앤매너가 보이는 디자인 |
| 공유 보너스 | 5pt | 단톡방에 공유하고 다른 수강생 명함에 리액션 |

| **달성 수준** | **획득 포인트** |
| --- | --- |
| 기본 제출 | 10pt |
| 기본 + 활용/창의성 | 15~20pt |
| 올클리어 (전항목 달성) | **25pt** |
